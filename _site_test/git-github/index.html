오늘 배운 것

Git은 저장 지점을 남기고 되돌릴 수 있게 해주는 도구다.

커밋까지의 세 단계

단계 명령 하는 일
1 git add 커밋에 담을 것을 고른다
2 git commit 고른 것을 한 덩어리로 기록한다
3 git push 기록을 GitHub로 올린다

가장 헷갈렸던 건 add와 commit이 왜 나뉘어 있는가였다. 파일을 두 개 고쳤는데 하나만 커밋하고 싶을 때가 있기 때문이었다.

막혔던 것

git log를 쳤더니 화면이 멈춘 것처럼 보였다. 알고 보니 기록을 보여주는 화면이 열린 것이었고, q를 누르면 빠져나온다.
