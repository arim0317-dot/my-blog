## 📝 소개

오늘은 Git의 기본 개념에 대해 배웠습니다. 매우 유용한 도구네요!

## 🎯 배운 것

### Git이란?
- 버전 관리 시스템
- 코드 변경 이력 추적
- 협업에 매우 유용

### 주요 명령어

```bash
git init           # 저장소 초기화
git add .          # 변경사항 스테이징
git commit -m ""   # 커밋
git push origin    # 원격 저장소에 업로드
```

## 💡 배운 팁

> 커밋 메시지는 명확하고 간단하게 작성하는 것이 중요합니다!

- 변경사항마다 커밋하기
- 의미 있는 메시지 작성
- 정기적으로 push하기

## ✅ 정리

Git을 배우면서 버전 관리의 중요성을 깨달았습니다. 
앞으로 모든 프로젝트에서 Git을 사용해야겠습니다.
