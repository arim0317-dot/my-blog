파일명

다운로드한 파일을 _posts/ 폴더에 넣고 git add · commit · push 하면 게시됩니다.

게시 전 셀프 체크리스트
  • STAR 구조(상황 · 과제 · 행동 · 결과)를 따르고 있는가?
  • 해결 과정(Action)이 글의 중심인가?
  • 기술 선택의 "왜"가 설명되어 있는가?
  • 비교/정리가 필요한 부분에 표를 사용했는가?
  • 흐름 설명에 Mermaid 다이어그램을 사용했는가?
  • "더 학습하면 좋은 개념" 섹션이 있는가?
  • 공식 문서 링크가 참고 자료에 포함되어 있는가?
  • 결과에 정량적 지표가 있는가?
